The app

Host local sites and services on Tor.

OnionHoster is an open-source desktop app for publishing static sites, already-running local servers, raw TCP services, and optional tunnels through Tor. It runs a local-only HTTP listener and registers it as a persistent onion service, so nothing is exposed directly to the clearnet.

  • Static folders and single HTML files, served from disk.
  • HTTP and HTTPS reverse proxying for local development servers.
  • Arbitrary TCP ports, such as SSH, through a Tor onion address.
  • Live Tor bootstrap progress, bridges, logs, and persistent keys.
